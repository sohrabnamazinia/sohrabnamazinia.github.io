Designed a <strong>multi-agent probabilistic framework</strong> for top-k package queries — minimizing expensive LLM oracle calls while guaranteeing optimality. Achieved a <strong>45% speedup</strong> and <strong>15–20× cost reduction</strong> vs. state-of-the-art. Also developed PromptXplorer for personalized prompt refinement using RAG and clustering-based composite prompt generation.</p>
